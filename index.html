01 · Agentic Orchestration

LangGraph Demo Suite — 4 Core Patterns

langgraph-dm.py

A self-contained walkthrough of the four fundamental LangGraph orchestration patterns, each implemented as an isolated, runnable function. Demo 1 builds a linear three-node pipeline (outline → draft → summarize) to show typed shared state and basic edge wiring. Demo 2 adds a conditional routing edge that sends queries to an answer node when context is retrieved, or to a fallback node when the mock knowledge base returns nothing — the canonical RAG branching pattern. Demo 3 uses create_react_agent with two tools (a safe expression evaluator and a mock web search) to demonstrate the ReAct think-act-observe loop without any manual graph wiring. Demo 4 implements a reflection loop in which a generation node and a critique node exchange state across back-edges until an iteration counter triggers termination — the pattern behind self-improving agent workflows.

02 · Vector Index Builder

ChromaDB RAG Papers Indexer

build_chromadb_rag_papers.py

A one-shot ingestion pipeline that downloads five foundational RAG papers directly from arXiv, extracts their text page-by-page, splits each into overlapping 1,200-character chunks with sentence-boundary awareness, embeds every chunk via text-embedding-3-small, and writes the resulting vectors — along with paper metadata — into a persistent local ChromaDB collection. The script is idempotent: re-running it drops and recreates the collection cleanly. PDFs are cached to disk so only the first run incurs download time. The output collection is ready to query with any ChromaDB client and serves as the vector store backend for a production-style RAG Q&A system. Papers covered span the original Lewis et al. RAG paper (2020) through a 2025 systematic literature review, giving the index broad coverage of retrieval-augmented generation techniques and evaluation practices.

03 · RAG Pipeline · CLI

Local RAG Q&A over Any PDF

rag_openai_local.py

A fully self-contained command-line RAG pipeline that works on any local PDF, plain-text, or Markdown file — or any PDF reachable by URL. The pipeline chunks and embeds the document on first run, saves the chunk index as JSON and the embedding matrix as a NumPy .npy file, then performs cosine-similarity retrieval (no external vector DB required) to surface the top-k passages most relevant to each question. A grounded-generation prompt strictly instructs the model to answer only from retrieved context and to cite chunks by ID, distinguishing document statements from inference. A --reload flag skips re-embedding on subsequent questions against the same document, making iterative Q&A sessions fast. Ported from a Jupyter notebook; the LlamaIndex path from the notebook is intentionally omitted in favour of the transparent manual pipeline.

cosine-similarity retrieval numpy dot-product search grounded generation chunk-ID citation save / reload index argparse CLI

Run

python rag_openai_local.py --file paper.pdf --ask "What is the main argument?" python rag_openai_local.py --url https://arxiv.org/pdf/2005.11401 --ask "Summarise contributions." python rag_openai_local.py --reload --ask "What datasets are used?"
